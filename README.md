# shchodennyy_kalendar — щоденний календар для «Сумського синоптика»

Автопост у Telegram-канал [@sumskoy_sinoptik](https://t.me/sumskoy_sinoptik) щодня о 10:00 за Києвом:
картка + текст (свята, церковний календар, іменини, Місяць, схід/захід Сонця в Сумах, легенда, народна прикмета, хештеги).

| Файл | Призначення |
|---|---|
| `shchodennyy_kalendar.py` | основний скрипт, формування посту, відправка |
| `shchodennyy_kalendar_card.py` | генератор картки 1080×1350 |
| `shchodennyy_kalendar_data.py` | **статичні дані** — редагуйте тут |
| `.github/workflows/shchodennyy_kalendar.yml` | розклад GitHub Actions |

## Запуск
Secrets у репозиторії: `BOT_TOKEN`, `CHAT_ID`. Бот має бути адміністратором каналу.

```bash
pip install -r requirements.txt
python shchodennyy_kalendar.py --dry-run                 # подивитись пост
python shchodennyy_kalendar.py --date 2026-12-25 --dry-run
python shchodennyy_kalendar_card.py --date 2026-12-25    # лише картка
```
Ручна публікація: Actions → «Щоденний календар» → Run workflow.

## Важливо
* Фази Місяця та схід/захід Сонця **обчислюються** (формули Меєра/NOAA), зовнішні API не потрібні.
* Великдень та похідні свята рахуються автоматично на будь-який рік.
* Церковні дати: новий календар (ПЦУ) і «(юл.)» — за юліанським.
* Cron GitHub інколи запізнюється на години. Тому розклад — 6 слотів (10:05/10:35/11:05/11:35 Києва в обох поясах), а скрипт публікує у вікні **10:00–12:59** за Києвом; від дублів захищає мітка в кеші Actions (один пост на дату). Ручний запуск публікує завжди.
* У публічних репозиторіях GitHub вимикає розклад після 60 днів без комітів — зробіть коміт або увімкніть workflow знову.
* Блок іменин заповнено частково — додавайте дати у `NAMES`; порожні дні просто пропускаються.
